ClassTempo — Classroom Timer Studio v2.2

This is a complete replacement for your existing ClassTempo repository.

NEW: A clearly visible End at a specific time shortcut directly below the timer in Wide and Narrow layouts.
Choose a time and press Start to time. The timer switches to Until a time and begins immediately.
It ends at that clock time on the same day, based on your computer's local clock.
Times already passed today are rejected without interrupting the current timer.
The original saved scenes, routines, design options, alerts, animations, and Wide/Narrow/Auto switch are preserved.

TO INSTALL ON GITHUB
1. Extract CT3.zip.
2. Replace the index.html file in your existing classtempo repository.
3. Commit and push. No Learning Hub changes are needed.
4. Refresh the published timer page (Ctrl + Shift + R if an old version remains cached).

SAVED SETTINGS
Your scenes are stored in your browser; replacing the website file does not erase them.
You can export a backup from ClassTempo before updating if desired.
